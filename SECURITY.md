# Security policy

MM ENGINE v0.1-alpha is experimental software intended for lawful homebrew research and development.

## Supported version

Security fixes are currently evaluated for the latest public `v0.1-alpha` source revision only. Older snapshots may not receive backports.

## Reporting a vulnerability

Please avoid publishing sensitive exploit details, private keys, credentials, console secrets, or proprietary SDK material in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use that channel. Otherwise contact the maintainer privately through the `Michele-M-Media` GitHub profile before opening a public issue that contains actionable security details.

A useful report includes:

- affected revision/commit;
- minimal reproduction steps;
- impact;
- whether the issue is in portable MM ENGINE code, the PS5 platform adapter, build scripts, or an external dependency;
- logs with private paths, IDs, credentials, and proprietary material removed.

## Scope

MM ENGINE does not request vulnerabilities in PlayStation platform security, anti-circumvention mechanisms, or unauthorized access. Reports should concern defects in MM ENGINE itself or in how its public build/runtime code handles data.
