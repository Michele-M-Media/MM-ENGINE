# Support MM ENGINE

MM ENGINE is an independent open-source project maintained by Michele Media.

Financial support helps fund continued development of the engine, PS5 hardware testing, build and validation infrastructure, documentation, tooling, and the work needed to investigate platform/runtime issues that cannot be resolved through workstation-only validation.

## GitHub Sponsors

The repository is configured to use the GitHub Sponsors profile for `Michele-M-Media`. When that profile is active and eligible, GitHub can display the **Sponsor** button directly on the repository.

Sponsorship is voluntary. The source remains open source under its published license, and sponsorship does not grant private ownership of the project, exclusive licensing rights, guaranteed features, or guaranteed support outcomes.

## Transparency

MM ENGINE is experimental community software. Funding helps development continue, but it does not change the validation standard used by the project: features should only be claimed when supported by source evidence and the corresponding validation level documented by the repository.

MM ENGINE is not affiliated with or endorsed by Sony Interactive Entertainment.
