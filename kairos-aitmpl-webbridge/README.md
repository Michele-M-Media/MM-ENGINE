# Kairos Forge MCP web gateway v0.9.0

This branch's `bridge-v0.1.tar.gz` is now the v0.9.0 source at the stable path consumed by the existing Render free service. It is a public, read-only catalog gateway with a typed AITMPL registry (8 categories), 15 read-only tools, compatibility with MCP 2025 and 2026-07-28 transport, an MCP diagnostics tool and `/health` endpoint.

Private files, shell execution, project writes, Desktop Commander actions, or third-party MCP execution are deliberately NOT exposed on this anonymous server. No commercial LLM API calls are made. Browser ChatGPT tool visibility requires selecting/refreshing the private plugin and has not been proven by deployment alone.
